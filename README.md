# TubeMute

TubeMute is an independent Android TV application
based on Android WebView.

## Features

- Android TV launcher support
- YouTube web interface
- Remote control navigation
- Fullscreen video support
- Experimental ad-skip functionality
- Gmail registration
- 7-day trial period
- License verification
- Ukrainian, English and Russian languages

## Requirements

- Android 5.0+
- Android TV device
- Internet connection
